# Revisión de las láminas pendientes

Se comparó cada una de las 52 láminas que quedaban tras la revisión de E03, E04, E05, E06, E07, E09, E10 y E12. Se contrastó el dibujo original con la vista de relleno y se volvió a inspeccionar la vista coloreada de cada lámina modificada.

Se actualizaron 37 láminas y se conservaron las 15 restantes. Cada lámina actualizada conserva sus revisiones publicadas para abrir dibujos guardados.

En la revisión del lote se comprobaron 289 puntos de relleno y pasaron las 207 pruebas de la app. El retoque posterior de M01 añadió 27 comprobaciones de relleno en las manchas, las patas y la hoja.
