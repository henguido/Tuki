# Capturas reales para Google Play

`source/` contiene seis capturas reales del Samsung SM-A325M, sin pantallas
ficticias: portada, selección de niveles, editores Fácil/Medio/Avanzado y
galería.

Estas fuentes son 1080 × 2400 y se conservan sin alterar como evidencia.

`prepared-phone/` contiene copias técnicas de 1080 × 2160 (relación 2:1), PNG
RGB sin alfa. Para no ocultar controles ni inventar contenido, cada captura
completa se redujo proporcionalmente al 90 % y se centró entre dos márgenes
negros de 54 px. No hay recorte, reconstrucción generativa ni cambio dentro de
la pantalla capturada.
